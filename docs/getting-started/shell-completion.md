# Shell completion

Completion is generated by cobra for bash, zsh, fish and PowerShell. It
completes commands, subcommands and flags at every level, and the id that
the commands of `vm`, `host`, `pool`, `sr`, `network`, `vdi`, `vbd` and
`pbd` take as their first argument (`xo vm start <TAB>`). zsh, fish and
PowerShell show each object's name beside its id.

Completing an id lists the objects with the selected profile: one request,
bounded by `--timeout`. Without a usable profile or server it completes
nothing. Task ids are not completed, and token ids never are: they are
secrets.

```sh
# bash (>= 4.4)
xo completion bash > /etc/bash_completion.d/xo     # or ~/.bash_completion.d/xo

# zsh
xo completion zsh > "${fpath[1]}/_xo"

# fish
xo completion fish > ~/.config/fish/completions/xo.fish

# PowerShell
xo completion powershell > xo.ps1
```

Each `xo completion <shell>` command prints its own install instructions with
`--help`:

```sh
xo completion bash --help
```
